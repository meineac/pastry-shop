8. Cellular Network Subscribers (OOP Inheritance)

Task Requirement (Variant 24): Implement an algorithm to analyze an array of cellular subscriber objects (operator, phone, callsCount in-network, totalDuration in minutes) to find all subscribers with the highest number of calls inside the network at the lowest average duration.

Architectural Requirement: Developed using a Base Class (Abonent: operator, phone) and a Derived Class (CellularAbonent: adds calls count and total duration), each containing 5 methods including getters/setters, form addition, array table rendering, and algorithm result display. Dual implementation: 1) Functional Prototypal Inheritance and 2) ES6 class/extends.
